# Mathematics for Machine Learning and Data Science

This specialization consists of three smaller courses:
- Linear Algebra: systems of equations, vectors, matrices, linear transformations, eigenvalues, eigenvectors, PCA, etc.
- Calculus: derivatives, partial derivatives, gradients, Hessian matrices, gradient descent and Newton's method algorithms, etc.
- Probability and Statistics: probability, probability distributions and functions (PMF, PDF, CDF), random variables, Bayes’ Theorem, statistical measures, point estimation, maximum likelihood, hypothesis testing, etc.
